# 北大楼模型参考与重建说明

本模型是依据南京大学公开立面图、照片制作的风格化外观模型，不是测绘模型或摄影测量扫描。以主体墙宽 15 个场景单位归一化，并与既有校园底座配合。保留照片中的灰瓦、青灰砖、石门框、塔楼假阳台及当代南面红星。

## 参考依据

- [南京大学档案馆：筑言·鼓楼 | 南京大学鼓楼校区北大楼](https://historymuseum.nju.edu.cn/info/1201/10711.htm)：南立面、东立面、塔顶实景、建筑形制说明。2026-09-18 查阅。
- [官方南立面图](https://historymuseum.nju.edu.cn/__local/D/52/29/DD46AFEDB39CCB0A1476A6789EC_B8BBBDEF_17627.png)：整体宽高、两层翼楼与五层塔楼、窗列与入口层次。
- [官方东立面图](https://historymuseum.nju.edu.cn/__local/B/2A/3B/77FE1F4E5A7C172378BAD3B297A_D21F5989_16D01.png)：进深、塔楼前后关系、歇山顶侧面和侧入口。
- [官方塔冠近照](https://historymuseum.nju.edu.cn/__local/B/D6/2D/66E56B29394C2D8EBB2282221D3_47AE3D3A_7B372.png)：交叉山墙、瓦垄、红星、灰色脊饰、三联窗与石栏。

上述图片只作为本地比对参考，不随网站发布。

## 可复现源文件

`scripts/build-north-building.mjs` 使用项目现有 Three.js 创建建筑几何，按材质合并后导出 `src/scene/models/north-building.glb`。执行 `npm run model:build` 即可再生成。模型由 Vite 作为带内容哈希的资产发布，避免更新时使用旧缓存。

所有尺寸使用完整宽高深，不混用方盒半尺寸。正面朝 +Z，竖直朝 +Y，主体中心位于 X=0、Z=0。塔楼靠南面稍突出。场景中的落点由 `NorthBuilding.tsx` 管理。

## 表现范围和简化

- 主楼两翼各十一列双层窗，塔身中段单窗，南面下层三联窗与上部四面三联窗，石栏假阳台。
- 主楼歇山顶由四面弯曲下檐、两面上坡及端部山墙构成。塔冠由交叉山墙、四面檐口、瓦垄、脊饰组成。
- 建筑没有室内；玻璃采用不透明反射色和分格。砖面与藤叶使用顶点颜色，无外部照片纹理依赖。
- 后立面的窗列以主体规律补全，非测绘级还原；屋脊神兽用小型曲线脊饰概括。藤叶分布为固定种子的风格化分布，并避开入口及主要窗户。
- 模型数据按材质合并，移动端沿用场景的分辨率与阴影降级。

`node scripts/build-north-building.mjs --inspection` 会额外生成被 Git 忽略的离线检查数据；`scripts/render-model-review.py` 可据此生成正面、侧面及斜视检查图。这些是几何检查图，不代表浏览器中的最终灯光和材质效果。

## 本轮验证

- `npm run model:check`：用网站同款 GLTFLoader 重新读取 GLB，检查坐标/索引有效性、落地和场景尺寸、屋檐避开塔楼、几何数量预算。
- 当前模型：105,640 个三角面、14 个材质批次，GLB 约 5.46 MB（本地 gzip 测量约 1.44 MB，实际传输取决于托管压缩策略）。
- 检查了四个角度的离线渲染，修正前檐穿过塔楼、脊饰悬空以及窗边砖面缺口。
- 浏览器控制连接故障使自动实机检查不可用；已确认本地预览 HTTP 200、GLB 解析及生产构建成功，未实测移动端帧率或浏览器截图。
